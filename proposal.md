## Description
I will remake the 2048 game and will allow users to open it in a new window and play until they lose. This is relevent to media arts as it is a famous computer game that will help me grow my programming skills!

## Features
- New window
	- A new window with a grid pattern will open making use of the pygame draw function.
- Random new tiles
	- When the play moves, new tiles will appear using the random library and an if statements.
- Win or Lose Function
	- Using conditional statements, this function will check if 2048 is reached, or if there's no more turn oppurtunities.

## Challenges
- I will need to learn more on how to create movement in my game.
- I will also need to learn how to combine matching tiles.
- I will need to do research on different fonts avaliable in pygame to make my 2048 stand out!

## Outcomes
Ideal Outcome:
- Ideally, my game will be fully playable with no lag. Players will be able to either reach 2048, leading them to a win screen, or will run out of space and recieve the lose screen! The look of the game will also be different from traditional 2048, allowing it to stand out!

Minimal Viable Outcome:
- Players will be able to move tiles and combine them, hopefully until reaching a win or lose screen.
